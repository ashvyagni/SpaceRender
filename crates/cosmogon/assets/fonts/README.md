# Fonts

* `Inter-Regular.ttf` — Inter by The Inter Project Authors, SIL Open Font License 1.1
  (`Inter-LICENSE`). Modified: the character-map entries in the Unicode Private Use Area
  (U+E000–U+F8FF) were removed so they don't shadow the Phosphor icon font, which lives
  there. No glyph outlines were changed.
* Icons: Phosphor (MIT), bundled by the `egui-phosphor` crate.
